# Regras do agente (Antigravity) para o NISIALAND
Siga o arquivo CLAUDE.md na raiz deste projeto: ele contém as regras do jogo e de economia de contexto.
Resumo obrigatório:
- Consulte docs/INDICE-MODULOS.md antes de abrir arquivos; busque antes de ler; leia só trechos.
- Use `git diff` para ver mudanças; não releia arquivos inalterados.
- Nunca abra node_modules, dist, package-lock.json, mídia (mp4/mp3/ogg/zip), app.js, style.css, index.legacy.html, nem a pasta backups.
- Prefira o modelo mais econômico para tarefas simples (renomear, textos, buscas); o mais forte só para arquitetura ou bugs difíceis.
- Registre decisões novas em docs/DECISOES.md.
- Feche o navegador de teste ao terminar.
